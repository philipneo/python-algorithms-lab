# Python Algorithms Lab

Advanced Python practice for algorithm design, graph theory, dynamic programming, and complexity analysis.

## Focus Areas

- Graph traversal and shortest paths
- Dynamic programming and memoization
- Search strategies
- Complexity analysis
- Testable algorithm implementations

## Included Modules

- `algorithms/graphs.py` - Dijkstra shortest paths and topological sort
- `algorithms/dynamic_programming.py` - longest increasing subsequence and edit distance
- `tests/test_algorithms.py` - pytest coverage for core behavior

## Run Tests

```bash
python -m pip install -r requirements.txt
pytest
```

## Why This Exists

This repo is for building stronger problem-solving habits: clear inputs, readable implementations, and tests that prove the algorithm works.
